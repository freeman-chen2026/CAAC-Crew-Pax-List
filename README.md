# 公务航空综合工具 (CAAC-Crew-Pax-List)

本应用包含 5 个核心功能模块，涵盖备案表生成、航班行程处理、航路整理及批复核对。

---

## 功能模块

### 📋 功能1：备案表生成
- **模板兼容**：支持上传**总调模板**或**华东（中南）区内模板**，系统自动通过文件名或表格特征识别。
- **机组自动匹配**：内置 **125 名**机组名单，自动匹配证件号码、执照号码、联系方式。
- **执照自动回填**：中国籍机组（18 位身份证）会自动将身份证号填入「执照号码」。
- **国籍识别**：支持 **180+ 国家/地区**三字码映射；如遇未知国籍代码（如 MHL、NZL 等），页面顶部会弹出红色警告。
- **智能扩展**：乘客数量超过模板默认行数时，自动在末尾插入行，并完整保留图片、合并单元格和行高格式。
- **自适应字号**：机组/乘客姓名过长时，自动缩小字号并调整行高，防止溢出。
- **日期计算**：自动根据 GD 单的 UTC 时间计算并转换北京时。

### 🌐 功能2：世界时行程 + 飞越/香港邮件
- **世界时转换**：上传航段 Excel，按飞机注册号分组，自动将北京时间转换为世界时（UTC）。
- **用途识别**：根据「用途」列自动区分 PAX 或 FERRY。
- **邮件生成**：支持一键生成「飞越许可邮件」和「HKBAC 代理需求邮件」。
- **EML 导出**：生成的邮件支持下载为 `.eml` 文件，双击即可在 Outlook 中打开，含签名图片和完整格式。

### ✈️ 功能3：航路处理工具
- 粘贴民航航线数据（支持表格格式或纯中文描述），自动提取、精简并整理成标准航路格式。

### 🔍 功能4：批复核对
- 上传批复汇总表 (`.docx`) + 航段数据 (`.xlsx`) + 文本航班信息。
- 自动核对机型、起降时间、用途（U/H vs N/M）及机组国籍标注。
- 输出核对结果表格，并在导出的 Word 中自动标红差异（如：待取消、待变更、国籍错等）。

### 📊 功能5：内地批复执行情况统计表
- 结合航段数据与批复表，自动生成内地批复执行情况统计。
- 自动填入执行架次、准点/非准点数量，并支持 SOBT 匹配。
