# 公务航空综合工具 (CAAC-Crew-Pax-List)

这是一个专为运行控制（AOC）/ 运控专员打造的 Streamlit 综合工具。集成了备案表生成、世界时行程整理、航路处理、批复核对及统计等功能，旨在减少日常航班申请与核对中的重复手工劳动。

---

## 📦 核心功能详解

### 📋 功能1：备案表生成
**核心用途**：通过上传标准的 GD 单（General Declaration）和对应模板，自动提取信息并填入备案表 Excel。
- **输入要求**：
  - `GD单`：必须是 `.xlsx` 格式的中文版。
  - `模板`：支持总调模板和华东（中南）区内模板。系统会优先通过**文件名是否包含“华东”或“总调”**来识别；若无标识，则通过读取模板第5列（E列）是否包含“国籍”字眼来智能判定。
  - `航段数据（可选）`：用于自动匹配时间并预填行程。
- **业务逻辑**：
  - **机组匹配**：读取 GD 单上的机组姓名，去代码内置的 `BUILTIN_CREW_DATA` 名单（现有 125 人）中匹配出对应的证件号、执照号、联系方式。
  - **执照号填充规则**：若匹配到的证件号为 18 位中国大陆身份证，系统会自动将该身份证号填入「执照号码」列。
  - **国籍处理**：系统内置了 180+ 国家的三字码映射表。若 GD 单出现未知三字码，页面顶部会弹出警告，且 Excel 中会原样输出该三字码。
  - **动态插行**：若乘客数量超过模板预留行数，系统会自动在末尾插入新行，并完美复制上一行的样式、合并单元格和行高。

### 🌐 功能2：世界时行程 + 飞越/香港邮件
**核心用途**：将 Jetops 导出的北京时航段数据，转换为标准的 UTC 世界时格式，并一键生成 OVF（飞越）和 HKBAC（香港代理）邮件。
- **输入要求**：航段数据导出 Excel。表头必须在**第二行**（或前10行内），必须包含：`飞机注册号`、`出发地`、`到达地`、`计划出发`、`预计到达` 等关键列。
- **业务逻辑**：
  - 自动将北京时间减去 8 小时转换为 UTC 时间。
  - 根据「用途」列判断 PAX 或 FERRY。
  - 自动隐藏纯内地计划。
  - 若航班涉及 `VHHH`（香港），可直接生成 HKBAC 代理需求邮件，系统会自动抓取进离港时间进行航班配对。
  - 生成的邮件支持下载为 `.eml` 格式，双击即可在 Outlook 中带格式打开，支持内嵌签名图片。

### ✈️ 功能3：航路处理工具
**核心用途**：清理并格式化杂乱的航路数据。
- 支持粘贴带坐标的航路表、或者纯中文描述。
- 自动精简重复的航路点，添加 `#` 前缀标识，输出标准的 `起飞点 航路1 航路2 降落地` 格式。

### 🔍 功能4：批复核对
**核心用途**：防止批复与计划不一致导致违规。
- **输入要求**：批复汇总表 (`.docx`) + 航段数据 (`.xlsx`) + 文本航班信息。
- **业务逻辑**：
  - 自动读取 Word 中批复的航班信息，与 Excel 计划、文本计划进行交叉比对。
  - 核对项：机型、起飞时间、飞行时长、用途（U/H vs N/M）、机组国籍。
  - 若有不一致，会在导出的 Word 里把错误的地方**标红高亮**，并自动追加“待取消”、“待变更”等备注。

### 📊 功能5：内地批复执行情况统计表
**核心用途**：每日生成准点率统计。
- **输入要求**：航段数据（北京时） + 统计模板。
- **业务逻辑**：
  - 按飞机注册号分组，自动填入执行架次、准点/非准点数量。
  - 支持结合批复表（Word）计算 SOBT 匹配度。
  - 自动更新模板中的汇总行和当月累计数据。
