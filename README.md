# 公务航空综合工具

本应用包含五个功能页签：

1. **📋 备案表生成**：从 GD 单（General Declaration）+ 模板生成公务飞行计划信息备案表，自动填充机组/乘客信息。支持总调模板和华东（中南）区内模板，自动识别。
2. **🌐 世界时行程 + 飞越/香港邮件**：上传航段 Excel，生成世界时（UTC）飞行计划文本；支持一键生成飞越许可邮件 / HKBAC 代理需求邮件（.eml 双击可在 Outlook 打开）。
3. **✈️ 航路处理工具**：粘贴表格/中文航路 → 自动整理成标准航路格式。
4. **🔍 批复核对**：上传批复汇总表 (.docx) + 航段数据 (.xlsx) + 文本航班信息，自动核对机型/起降时间/用途/国籍，标红差异。
5. **📊 内地批复执行情况统计表**：结合航段数据 + 批复表，生成内地批复执行统计（含准点率、SOBT 匹配）。

---

## 功能1：备案表生成

- 上传 **GD 单 Excel**（中文版 .xlsx）和**备案表模板**（.xlsx）
- 自动识别模板类型：
  - 文件名含「华东」→ 华东区内模板（7 列：职务/姓名/性别/出生日期/**国籍**/证件号码/执照号码）
  - 文件名含「总调」→ 总调模板（7 列：职务/姓名/性别/出生日期/证件号码/执照号码/**联系方式**）
  - 无关键字时按模板内容自动判断
- 内置 **125 名机组名单**，自动匹配证件号码 / 执照号码 / 联系方式
- 中国籍机组（18 位身份证）自动把身份证号也填入「执照号码」列
- 乘客国籍支持 **180+ 国家/地区**三字码映射（MHL、NZL、BMU、CYM 等公务机常见国家/地区均支持）
- 未在映射表里的三字码会在页面顶部 **弹出警告**，列出具体代码
- 机组/乘客姓名过长时自动缩小字号并调整行高
- 乘客数量超过模板行数时 **自动在末尾插入行**，完整保留图片/合并/行高
- 自动根据 UTC 时间计算北京时间日期
- 可自定义航班行程显示格式

## 功能2：世界时行程 + 飞越/香港邮件

- 上传包含航段信息的 Excel 文件（表头在第二行）
- 按飞机注册号分组生成计划
- 北京时间自动转换为世界时（UTC）
- 根据「用途」列自动区分 PAX 或 FERRY
- 结果可直接复制粘贴
- **飞越邮件 / HKBAC 邮件**：选择航班后一键生成带签名、带格式的邮件，可下载为 `.eml` 文件双击在 Outlook 打开
- 支持上传签名图片（自动以 base64 内嵌到邮件）
- 内置机型 / 机组 / Operator / Billing Account 映射，可自定义

## 功能3：航路处理工具

- 粘贴民航航线数据（支持表格格式或纯中文描述格式）
- 自动整理成标准航路格式

## 功能4：批复核对

- ① 上传国内批复信息汇总表 (.docx)
- ② 上传航段数据导出 (.xlsx)
- ③ 粘贴文本版航班信息
- 自动核对：机型 / 起降时间 / 用途（U/H vs N/M）/ 国籍标注
- 输出核对结果表格，标红差异
- 下载标注后的批复汇总表

## 功能5：内地批复执行情况统计表

- 上传航段数据（北京时间）+ 统计模板
- 自动填写执行架次 / 准点 / 非准点 / 晚点原因
- 支持 SOBT（计划撤轮挡时间）匹配（来自批复表，可选上传 .docx）
- 输出可直接下载的 Excel
