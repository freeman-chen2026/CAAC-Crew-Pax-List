# 公务航空综合工具

本应用包含两个独立功能：

1. **备案表生成**：从 GD 单（General Declaration）和模板生成公务飞行计划信息备案表，自动填充机组/乘客信息。
2. **世界时行程**：将航段 Excel 转换为世界时（UTC）飞行计划文本，便于复制粘贴。

---

## 功能1：备案表生成
- 上传 GD 单 Excel 和备案表模板（.xlsx）
- 自动提取机组和乘客信息，填充到模板
- 支持内置联系方式、执照号码、身份证号码映射
- 自动根据 UTC 时间计算北京时间日期
- 可自定义航班行程显示格式

## 功能2：世界时行程
- 上传包含航段信息的 Excel 文件（表头在第二行）
- 按飞机注册号分组生成计划
- 北京时间自动转换为世界时（UTC）
- 根据“用途”列自动区分 PAX 或 FERRY
- 结果可直接复制粘贴

---
